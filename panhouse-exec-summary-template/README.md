# PanHouse 顧客向け1枚もの（エグゼクティブサマリー）デザインテンプレート

サンメッセ株式会社向け（2026/7）で確立し、ヤマト運輸向け（2026/8）でHTML化した正式デザイン。
**藤田さん確認済み：今後の顧客向け1枚資料（エグゼクティブサマリー・実施結果サマリー等）はこのデザインで作成する。**

## ファイル

- `エグゼクティブサマリー_テンプレート.html` … 提案・料金・スケジュールの1枚（ヤマト運輸版がベース。社名・数字を差し替えて使う）
- `実施結果サマリー_テンプレート.html` … トライアル研修結果報告の1枚

## デザイントークン

- フォント: `"Meiryo", "Yu Gothic", sans-serif`
- ネイビー: `#1f3864`（見出し・帯・表ヘッダー・バー）
- オレンジ: `#ed7d31`（強調数字・ご提案ハイライト・締切）／帯内の大数字は明るめ `#f4a53c`
- ハイライト行の背景: `#fbe5d6`／カード背景: グレー `#f5f5f7`・ブルー `#eaf0f9`
- A4縦1枚厳守（`@page { size: A4; margin: 0 }`、body `width:210mm; min-height:297mm`）

## 構成（エグゼクティブサマリー）

1. ヘッダー（宛先 御中／右に日付・社名・営業担当）＋ 大見出し「生成AI研修　エグゼクティブサマリー」
2. ネイビー帯：ご提案の構成 ―（1行）／「定価 X万円 → 助成申請成功時の実質負担 **Y万円**（オレンジ大）」／最小構成の注記
3. `01 ご提案の軸`：カード2枚（左グレー・右ブルー。見出し→仕様行→オレンジ大数字→本文→下線区切りの注記）
4. `02 料金試算`：オレンジのリード文「1名あたり実質 約20万円。人数が増えても単価は変わりません。」＋ 表（受講人数／定価合計／実質負担／助成金でカバーされる額。ご提案行を `◀ ご提案` でハイライト）＋ 注記3行
5. `03 締切逆算`：見出し「助成金の期限から逆算すると、X月中の意思決定が必要です」＋ オレンジ警告文 ＋ 月軸ガント（意思決定バーだけオレンジ、右端に破線＋「2027/3/31 助成金終了」）

## PDF化コマンド（headless Edge）

```bash
msedge --headless --disable-gpu --no-pdf-header-footer --print-to-pdf="出力.pdf" "file:///パス/入力.html"
```

生成後は必ず pypdf でページ数=1 を確認（`min-height:297mm` のため数mm溢れると2ページ目ができる）。
溢れたら `.sec` の margin・表の padding・ガント行の padding を 0.2mm 刻みで詰める。

## 数字のルール

- 料金・助成率は正本（info-train-service スキル）から引く。40万円/人・大企業区分 約50% → 実質約20万円/人
- アンケート集計値は回答スプシから直接カウントした実数のみ使う
